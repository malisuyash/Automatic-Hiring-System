# HushHush Recruiter — Automatic Hiring System
 HushHush Recruiter is a MERN stack-based automated recruitment platform that streamlines the hiring process using GitHub and StackOverflow activity data. It uses machine learning to cluster and evaluate candidates, helping companies like Doodle find top talent without relying on third-party recruiters.

# Project Objective:
Doodle, a global leader in IT and software development, wanted to automate its talent acquisition process. Instead of using traditional recruiting firms, Doodle requested an in-house secretive system to:

- Identify potential candidates based on their public developer profiles.

- Automatically notify shortlisted candidates.

- Allow them to solve timed coding questions.

- Enable hiring managers to evaluate and respond with final results — all with minimal manual intervention.
